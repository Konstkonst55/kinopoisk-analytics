# Kinopoisk Analytics

Система предназначена для интеллектуальной обработки неструктурированных пользовательских рецензий на фильмы. Проект выполняет очистку текстов, извлечение числовых оценок, динамическое выделение аспектов обсуждения, определение эмоциональной окраски по каждому аспекту и генерацию лаконичного вердикта на основе агрегированных мнений.

## Быстрый запуск

### Подготовка файлов

Исходные текстовые данные необходимо разместить в корневой директории в папке `data/`, распределив их по подпапкам тональности: `data/neg`, `data/pos` и `data/neu`. Датасет можно скачать на [Kaggle](https://www.kaggle.com/datasets/mikhailklemin/kinopoisks-movies-reviews).

### Обучение

Запуск процесса обработки данных и обучения моделей осуществляется через `Docker`

```Bash
docker-compose -f docker-compose.train.yml up --build
```

Эта команда последовательно запустит контейнеры: `preprocess` (подготовка датасетов), `train_w2v` (обучение эмбеддингов), `train_absa` (модель классификации) и `train_summary` (дообучение T5).  

### Запуск API

Для старта основного API сервиса

```Bash
docker-compose up --build -d
```

Данная команда поднимет контейнеры `Redis` и `FastAPI` сервера.

### Проверка работоспособности

Для выполнения тестового запроса к запущенному API используйте встроенный скрипт

```Bash
python tests/test_inference.py <movie_id>
```

Скрипт обратится к локальному серверу по адресу http://localhost:8000/api/v1/movie и выведет статистику по аспектам, среднюю оценку пользователей и сгенерированное саммари.

## Настройка конфигураций

Основные системные переменные, такие как `REDIS_URL`, `DATA_DIR`, `LOG_FILE` и пути к ресурсам, задаются в конфигурационном файле [backend/config.py](backend/config.py).

Гиперпараметры обучения вынесены непосредственно в файлы моделей. Для их изменения необходимо отредактировать исходный код в следующих файлах:

| Название         | Файл настройки                                           | Доступные параметры                                                                                                      |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| ABSA (BiLSTM)    | [models/absa_model.py](models/absa_model.py)             | `MAX_SEQ_LEN` = 50,<br>`BATCH_SIZE` = 128,<br>`EPOCHS` = 3,<br>`TRAIN_SAMPLES` = 25000,<br>`SIMILARITY_THRESHOLD` = 0.55 |
| Aspect Extractor | [models/aspect_extractor.py](models/aspect_extractor.py) | `n_clusters`=4<br>(инициализируется при вызове класса)                                                                   |
| Summarizer (T5)  | [train/train_summary.py](train/train_summary.py)         | Настраивается при вызове метода `train`:<br>`epochs`, `batch_size`, `lr`                                                 |

Пример конфигурации параметров саммаризатора в стартовом скрипте [train/train_summary.py](train/train_summary.py):

```Python
model.train(train_data=train_data, epochs=3, batch_size=4, lr=3e-5)
```

## Описание данных

Структура датасета представляет собой сырые текстовые файлы, распределенные по папкам `neg`, `neu` и `pos`. Имя каждого файла должно содержать идентификатор фильма, отделенный дефисом, например `movie_id-review_id.txt`. Текстовый документ содержит сырую рецензию, внутри которой может находиться пользовательская оценка в формате "X из 10".

Процесс предобработки, реализованный в `data_pipeline/preprocess.py`, нормализует текст, удаляя лишние пробелы, и ищет специфичные [маркеры](resources/markers.csv) выводов (например, "В итоге:"). На основе обработанных файлов генерируются два структурированных датасета в формате `Parquet`, которые сохраняются в `data/processed/`:

| Датасет            | Назначение               | Содержимое                                                                                                              |
| ------------------ | ------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `dataset1.parquet` | Обучение ABSA и Word2Vec | Идентификатор фильма, нормализованный полный текст, целочисленная метка тональности и извлеченный рейтинг пользователя. |
| `dataset2.parquet` | Дообучение модели T5     | Идентификатор фильма, исходный полный текст и извлеченное короткое резюме (summary).                                    |

## Описание реализации

Выделение аспектов фильма осуществляется динамически на основе контекста текстов. Система использует алгоритм `Custom Seeded K-Means` и эмбеддинги обученной модели `Word2Vec`. Векторизуются лемматизированные кандидаты из отзывов, а в качестве стартовых центроид алгоритму передаются [якорные термины](resources/cinema_aspects.csv) (сюжет, каст, визуал). Используя метрику евклидова расстояния, извлекаются актуальные тематики.

Аспектно-ориентированный анализ тональности (`ABSA`) реализован с помощью архитектуры `BiLSTM`. Тексты бьются на предложения, к ним применяется кастомный лемматизатор [`CustomLemmatizer`](utils/lemmatizer.py), удаляющий [стоп-слова](resources/stop_words.csv) и [суффиксы](resources/suffixes.csv). Предложения фильтруются по косинусному сходству с вектором аспекта, после чего нейросеть предсказывает класс тональности (позитив, негатив, нейтрально).

Генерация итогового вердикта построена на базе трансформера T5 [`IlyaGusev/rut5_base_sum_gazeta`](https://huggingface.co/IlyaGusev/rut5_base_sum_gazeta), предварительно файнтюненного на кастомном датасете `dataset2.parquet` с применением оптимизатора `AdamW` и `GradScaler`. При генерации используется `GenerationConfig` с параметрами `no_repeat_ngram_size=3` и `repetition_penalty=2.5` для блокировки зацикливаний текста.

## Описание API

Веб-сервис реализован с использованием фреймворка `FastAPI`. Для ускорения отдачи ответов настроено кеширование в `Redis` (`fastapi-cache2`) со сроком жизни ключа 86400 секунд.

| Маршрут                            | Метод | Описание                                                                                                                             | Формат ответа (Pydantic Model)                                                                                                                     |
| ---------------------------------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api/v1/movie/{movie_id}/aspects` | GET   | Извлекает рецензии для фильма, динамически кластеризует аспекты и предсказывает процентное распределение тональностей по каждому.    | <br>`AspectResponse`: Идентификатор фильма и словарь `aspects`, содержащий объекты с полями `pos`, `neg`, `neu` и счетчиком упоминаний `mentions`. |
| `/api/v1/movie/{movie_id}/summary` | GET   | Агрегирует тексты, генерирует общий текстовый вердикт с помощью T5 и высчитывает средний рейтинг среди всех ненулевых оценок фильма. | <br>`SummaryResponse`: Идентификатор фильма, строка `summary` и средняя оценка зрителей `average_rating`.                                          |
